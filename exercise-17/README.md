# Exercise 17: Resolve Merge Conflict in VS Code

## Aim
To resolve merge conflicts using Visual Studio Code.

## Steps
1. Open the repository in VS Code.
2. Create two branches and modify the same lines of a file differently.
3. Merge one branch into the other.
4. Open the conflicted file in VS Code.
5. Choose **Accept Current Change**, **Accept Incoming Change**, or **Accept Both Changes**.
6. Save the file after resolving the conflict.
7. Stage and commit the resolved file.

## Explanation
VS Code highlights conflicting changes and provides options to choose which content to keep.

## Result
Learned the steps for resolving a merge conflict using VS Code.
