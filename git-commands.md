# Git Commands Practice

This file contains the Git commands used during the assignment and their purposes.

| Command | Purpose |
|---|---|
| `git --version` | Checks the installed Git version. |
| `git config --global user.name "Arya Malik"` | Sets the Git username. |
| `git config --global user.email "aryamalik15059@gmail.com"` | Sets the Git email. |
| `git config --global init.defaultBranch main` | Sets the default branch name. |
| `git init` | Creates a Git repository in the current folder. |
| `git status` | Shows the current file and repository status. |
| `git add .` | Stages changes for a commit. |
| `git commit -m "message"` | Saves staged changes as a commit. |
| `git log --oneline` | Displays a short commit history. |
| `git branch` | Lists local branches. |
| `git switch -c branch-name` | Creates and switches to a new branch. |
| `git merge branch-name` | Merges another branch into the current branch. |
| `git remote -v` | Displays configured remote repositories. |
| `git push` | Uploads commits to a remote repository. |
| `git pull` | Downloads and integrates remote changes. |
