# Exercise 16: Git in VS Code

## Aim
To learn how to use Git through the Source Control panel in Visual Studio Code.

## Steps
1. Open the project folder in VS Code.
2. Select the Source Control icon from the sidebar.
3. Review the modified files.
4. Stage a file using the `+` icon.
5. Enter a commit message.
6. Click Commit to save the changes.
7. Use Sync Changes or Push to upload commits to GitHub.

## Explanation
The Source Control panel provides a graphical way to view changes, stage files, commit changes and synchronize with a remote repository.

## Result
Documented the basic Git workflow in VS Code.
