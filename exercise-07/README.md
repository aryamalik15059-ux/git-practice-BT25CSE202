# Exercise 07: Menu-Driven Shell Program

## Aim
To create a shell script using a menu and a case statement.

## Menu Options
1. Greeting
2. Addition of two numbers
3. Check whether a number is even or odd
4. Exit

## How to Run
```bash
bash menu.sh
```

## Sample Output
```text
1. Greeting
2. Addition
3. Even or Odd
4. Exit
Enter choice: 2
Enter two numbers: 5 7
Sum = 12
```

## Result
Created a menu-driven shell program using a loop and case statement.
