# Exercise 04: Stage Selected Files

## Aim
To learn how to stage selected files in Git.

## Files
- `file1.txt`
- `file2.txt`

## Commands
```bash
git add exercise-04/file1.txt
git status
git add exercise-04/file2.txt
git status
git commit -m "Stage selected files"
```

## Result
Learned how to stage specific files instead of staging all changes at once.
