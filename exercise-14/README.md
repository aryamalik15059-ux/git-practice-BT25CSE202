# Exercise 14: Collaboration Using GitHub

## Aim
To collaborate using branches, pull requests and code reviews.

## Steps
1. Create a new branch for the changes.
2. Make changes to the project.
3. Commit the changes to the branch.
4. Open a pull request to propose merging the changes into `main`.
5. Review the changes.
6. Merge the pull request.

## Commands
```bash
git switch -c feature-branch
git add .
git commit -m "Add feature"
git push -u origin feature-branch
```

## Explanation
- A branch allows work to be done separately from `main`.
- A pull request proposes merging changes into another branch.
- A review allows another person to examine the changes before merging.

## Result
Learned the basic workflow for collaboration using GitHub branches and pull requests.
