# Exercise 18: Create a Release Tag

## Aim
To create a Git tag named `v1.0` for a release.

## Commands
```bash
git tag
git tag v1.0
git tag
git show v1.0
git push origin v1.0
```

## Explanation
- `git tag` lists the available tags.
- `git tag v1.0` creates a tag for the current commit.
- `git show v1.0` displays information about the tagged commit.
- `git push origin v1.0` pushes the tag to GitHub.

## Result
Learned how to create and publish a Git release tag.
