# Exercise 05: Inspect Changes

## Aim
To learn how to inspect changes made to files using Git.

## Commands and Their Uses

```bash
git diff
```
Shows changes that have not been staged.

```bash
git diff --staged
```
Shows changes that have been staged.

```bash
git diff HEAD
```
Shows all changes compared with the latest commit, including staged and unstaged changes.

## Result
Learned how to inspect file changes before committing them.
