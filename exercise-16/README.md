# Exercise 16: Git in VS Code

## Aim
To learn how to use Git through the Source Control panel in Visual Studio Code.

## Steps
1. Open the project folder in VS Code.
2. Click the Source Control icon in the sidebar.
3. Check the modified files.
4. Click the `+` icon to stage a file.
5. Enter a commit message.
6. Click Commit to save the changes.
7. Push the changes to GitHub.

## Result
Learned the basic Git workflow using the Source Control panel in VS Code.
