# Exercise 01: Git Setup
## Aim
To check Git installation and set up the username, email and default branch.
## Commands Used
```bash
git --version
git config --global user.name "Arya Malik"
git config --global user.email "aryamalik15059@gmail.com"
git config --global init.defaultBranch main
```
## Expected Output
Git version is displayed successfully. The username, email and default branch are configured.
To check the settings, use:
```bash
git config --global --list
```
## Result
Git installation and basic configuration are completed.
