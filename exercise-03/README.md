# Exercise 03: Greeting Script

## Aim
To write a Bash script that greets the user and handles empty input.

## File
greet.sh

## How to Run
Open Git Bash in the folder containing the script and run:

```bash
bash greet.sh
```

## Sample Output 1
Enter your name: Arya
Hello, Arya!

## Sample Output 2
Enter your name:
Name cannot be empty

## Commits
1. Add basic greeting script
2. Add empty input validation

## Result
The script prints a greeting for a non-empty name and displays an error message for empty input.
