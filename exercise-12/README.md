# Exercise 12: Git Stash

## Aim
To temporarily save unfinished changes using Git stash.

## Commands
```bash
git stash
git stash list
git stash pop
```

## Explanation
- `git stash` temporarily saves tracked, uncommitted changes.
- `git stash list` displays saved stashes.
- `git stash pop` reapplies the latest stash and removes it from the stash list if successfully applied.

## Result
Learned how to save unfinished work temporarily and restore it later.
